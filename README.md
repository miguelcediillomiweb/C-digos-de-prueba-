# Códigos de prueba · Ruta 1371

Este repositorio es el laboratorio de vistas previas. Aquí se reemplazan los archivos de la prueba vigente; no se modifica la web de producción hasta que Miguel apruebe la escena.

## Archivos
- `index.html`: estructura de la vista.
- `css/escena.css`: paisaje, camión y animaciones.
- `js/escena.js`: hora local, fase lunar y clima real de Open-Meteo para Reyes Acozac (19.71, -98.97).

## Publicación
Activa GitHub Pages en Settings → Pages → Deploy from a branch → main → /(root). La vista se publica en:
https://miguelcediillomiweb.github.io/C-digos-de-prueba-/

La vista usa Open-Meteo sin clave API. Los botones de clima son controles de prueba; Automático usa la consulta meteorológica real.
